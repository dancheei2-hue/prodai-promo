# Продай сам

Готовая версия сайта «Продай сам».

В этой версии:
- обновлена логика позиционирования продукта;
- добавлен блок «Честный подход»;
- добавлен расчёт объёма самостоятельной работы;
- добавлена интерактивная самодиагностика;
- обновлены тексты покупки курса и услуг;
- сохранены существующие изображения и адаптивная верстка.

Для публикации на GitHub достаточно заменить содержимое репозитория файлами из этого архива.

Для локального запуска:
1. `npm install`
2. `npm run dev`

Для сборки:
`npm run build`

## Доступ к обучению

Публичная кнопка «Посмотреть, что предстоит сделать» ведёт к блоку с 6 этапами продажи.

Само обучение закрыто экраном пароля. Текущий демонстрационный пароль: `PRODAI2026`.

Чтобы изменить пароль, замени значение `COURSE_PASSWORD` в `src/main.jsx`.

Важно: это клиентская защита для статического GitHub Pages-сайта. Пароль нельзя считать полноценной серверной защитой или защитой платного контента от технически подкованного пользователя. Для настоящей платной авторизации позже понадобится серверная/внешняя система доступа.
