# Продай сам

Готовая версия сайта «Продай сам».

В этой версии:
- обновлена логика позиционирования продукта;
- добавлен блок «Честный подход»;
- добавлен расчёт объёма самостоятельной работы;
- добавлена интерактивная самодиагностика;
- обновлены тексты покупки курса и услуг;
- сохранены существующие изображения и адаптивная верстка.

Для публикации на GitHub достаточно заменить содержимое репозитория файлами из этого архива.

Для локального запуска:
1. `npm install`
2. `npm run dev`

Для сборки:
`npm run build`
